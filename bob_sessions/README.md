# Bob Sessions

This folder is where exported IBM Bob session logs go, as evidence of
IBM Bob being used during development of WhyBroke.

## How to add your sessions

As you build with Bob during the hackathon, export or save your session
transcripts here (e.g. `bob_sessions/2026-09-26-regression-engine.md`), so
judges can see the actual development process, not just the end result.

## Honesty note

This starter project does not include fabricated session logs. Add your
own real exports here as you work. See the main README's "How IBM Bob Is
Used" section for how this project's development is intended to use Bob,
and update that section to reflect what you actually did if it changes.
